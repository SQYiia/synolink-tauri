`example.heic` is the public libheif example used for the optional real-browser codec test.
Source: https://github.com/strukturag/libheif/blob/master/examples/example.heic
Upstream license: https://github.com/strukturag/libheif/blob/master/COPYING

Run `npm run test:heic` with Chrome installed (or set `CHROME_PATH`).
The test uses an isolated headless browser and the application's production CSP.
