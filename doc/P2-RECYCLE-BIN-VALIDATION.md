# P2 回收站管理

版本维持 0.1.19，源码沿用 dev 分支。不提前发布 0.1.20，P0 和相册自动备份仍待安卓真机验收。

## 入口与功能

- Windows 文件页工具栏“回收站”；安卓文件页右下角更多菜单“回收站”。共用同一组件和来源身份校验。
- 选择当前账号可访问的共享目录，浏览该目录的 `#recycle`。每页 100 项，支持上下页、子目录进入/返回、当前页名称筛选、当前页全选及逐项勾选。
- 未启用、无权限或目录不存在时显示访问错误，不误报为空回收站。不会自动开启 NAS 回收站或修改共享目录设置。
- 恢复到用户指定的已存在目录，提交前确认并检查大小写/Unicode 近似同名项目，不覆盖、不合并、不推断原始路径。
- 恢复复用 CopyMove 移动任务：来源、目标目录标记刷新，进度、查询、取消和部分失败使用现有传输中心。当前目录有未结束的恢复任务时禁用恢复/删除，避免重复提交。
- 永久删除只允许选中的回收站子项目，明确告知目录内容也会删除并二次确认；不提供整台 NAS 一键清空，不允许删除回收站根目录。
- 删除使用 Delete v2 阻塞接口，检查整体/逐项错误，随后重新读取父目录核对所选项目是否已不存在。请求中断或结果不明保留提示、禁用继续删除，用户须手动刷新核实；不自动重试。
- 切换账号、会话变化或页面失活会关闭面板、丢弃旧查询结果；已提交的 NAS 写操作可能继续，不以关闭面板冒充取消。后续查询/写请求绑定原来源客户端。
- 不包含 Synology Drive 专用回收站、删除时间/删除者统计、自动过期清理、原位置恢复、跨页选中或递归搜索。普通文件页原有删除行为未改动。

## 接口依据

群晖官方知识库说明共享目录回收站通过 `#recycle` 访问：[删除文件与文件夹](https://kb.synology.com/en-sg/PAS/help/FileStation/delete?version=1_0)、[恢复误删文件](https://kb.synology.com/en-af/DSM/tutorial/How_do_I_restore_files_deleted_from_Synology_NAS)。

本次未猜测未公开的 Restore 接口；使用已公开 List、CopyMove、Delete 接口完成浏览、移动恢复和删除。参数与任务状态依据仓库 `doc/Synology_FileStation_API.md`。运行前发现并确认 List/Delete v2、CopyMove v3；接口缺失时停止操作。

## 验证与待验收

- Node 回归 96 项通过，其中新增 5 项覆盖回收站边界、根目录/跨目录/路径穿越拒绝、返回项目校验、恢复目录限制、删除部分失败以及接口版本发现。
- `npm run test:recycle`：模拟 NAS 的桌面/手机入口、分页、嵌套目录、同名冲突、恢复完成刷新、删除成功、取消确认、未知结果不重试、访问权限失败和账号切换丢弃旧响应。
- `npm run test:files`：分享、压缩、解压、批量重命名及既有文件操作回归。
- Vue 类型检查、前端生产构建及安卓 ARM64 编译验证；未签名 APK 仅作为编译检查，不发布安装包。
- 真实 NAS 待验收：回收站权限、不同 DSM 版本返回结构、恢复目录内容一致性、恢复取消后实际目录状态、同名并发变化、永久删除后的真实文件状态。
- 安卓真机待验收：触摸/返回键/目录选择器及会话切换行为。浏览器窄屏测试不能替代设备验证。

当前无真实 NAS 写操作验收，也无安卓真机测试结果，不将模拟测试标记为生产环境验收通过。
