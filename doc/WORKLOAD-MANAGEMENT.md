# 容器与虚拟机管理增量（2026-11-14）

- 容器详情：只读显示端口映射、挂载、网络、重启策略、健康状态及退出码。缺失字段显示未知；环境变量不进入详情，避免直接展示密码。
- 容器日志：当前页关键词过滤、复制、JSON 导出；首页可每 5 秒自动刷新，切后台或离开页面停止调度。只导出当前页筛选结果，最大 256 KiB。Windows 使用保存对话框，Android 使用现有原生文档保存桥接，文件名为 SynoLink-container-log.json；取消不会改变 NAS。
- VMM 任务面板：只读查询 Task.Info/list/get，每批最多两项查询。进度 100% 不代表结束；finish 为 true 才显示已结束，已知错误优先显示失败。单项请求中断显示等待查询。接口未提供时显示原因，不提交未知接口。
- VMM 电源指令不保证返回异步任务 ID，继续通过虚拟机列表观察状态；任务面板不假称覆盖全部 DSM 作业。
- VMM 查询改为各分区独立处理；缺失资源显示 —；离开页面、换账号或会话后忽略旧结果，并防止重复刷新使请求卡住。

## 验证范围

自动测试覆盖详情字段白名单、未知值、任务结束与错误分类、VMM 部分接口失败、重复查询、页面失活、会话变化及旧操作回调。
浏览器回归覆盖容器启停、桌面及手机尺寸详情、日志筛选、VMM 配置与任务显示，以及现有媒体／套件等功能。
类型检查、生产构建和 Windows NSIS 构建用于本次交付。

真实 NAS 返回字段、Windows 安装后运行、安卓系统导出、通知／后台下载等真机项目仍待验证；手机尺寸浏览器测试不代替安卓设备测试。本轮不发布 0.1.20。
