# P0 开发与验证状态（未发布）

本批按计划统一交付，不单独发布诊断页面。当前版本号保留为 0.1.19，0.1.20 正式发布等待验收。

## 已实现

- 设置中的连接诊断：逐项结果、取消、KeepAlive 离开后失效、账号切换清空；成功响应中的缺失容量/性能数据显示警告。
- 最近错误：按来源身份哈希分区，仅保留白名单字段，最近 100 条/7 天，支持清空；DSM、图片及下载失败接入。
- 报告复制和 JSON 导出；Windows 保存对话框，Android 系统文档选择器。
- Android 完成文件保存/分享，Rust 以任务 ID 查找完成文件，FileProvider 仅开放专用分享缓存。
- Android Rust 原生下载调度，两个并发；同来源账号恢复，凭据仅驻留内存，取消后重复启动保护，旧前端记录保留。
- dataSync 前台服务、总体进度通知、取消全部、系统超时停止，Android 13+ 通知权限请求。

## 验证结果

- Node：74 项通过，包括日志隔离/脱敏/保留上限、缺失字段诊断和取消结果丢弃。
- Rust：11 项通过，包括下载数据完整性、续传相关已有回归、原生并发上限及任务元数据不包含凭据。
- 浏览器：诊断页面、缺失容量提示、报告中无模拟会话信息，以及已有媒体/套件流程通过。
- Android ARM64：最终 release APK 编译通过；原生桥接和服务类在 R8 映射中保留。构建产物未签名、未发布。
- 手机浏览器：竖屏及横屏 UI smoke 检查通过；不代表原生后台行为通过。

## 必须补做的设备验收

当前没有连接的 Android 设备；用户选择保留待验证，不将模拟浏览器验证视为真机通过。

- Android 13、15/16：首次允许/拒绝通知；锁屏与切应用后下载；通知取消；系统 dataSync 超时。
- 断网重连、证书错误、权限拒绝、会话失效和两次重试上限。
- 进程终止后重新打开并登录来源账号恢复；修改过的远端文件不错误拼接。
- 保存/分享长文件名和大文件、存储不足、文件不存在、取消选择器；用接收应用打开并校验内容。
- Android 7–12 分支兼容性、系统后台限制。

正式发布前需完成上述验收、签名 APK、Windows EXE/MSI、校验文件和 GitHub 最新版本接口验证。当前不推送或发布不完整的正式版本。
