# P1：Jellyfin 播放（待服务联调）

实现日期：2026-11-13。版本仍为 0.1.19；不改变 P0 等待安卓真机验收后统一发布的安排。

## 已实现

- 电影与单集详情的播放、继续观看和从头播放入口。
- 独立深色播放器，桌面与手机布局，原生视频控制、音轨、字幕和最高码率选择。
- 使用 Jellyfin PlaybackInfo 协商 H.264/AAC HLS 流；兼容源允许服务端复制流，不兼容源由服务端转码。当前不提供直接播放原始文件或外部打开。
- 字幕采用服务端烧录；切换字幕、音轨与码率会重新协商，保留当前位置。需要账号允许对应转码。
- 开始、暂停、跳转、定时进度与停止事件同步到 Jellyfin；关闭、离开页面或切换 NAS 账号时清理播放会话。
- 播放清单与分片通过原生 HTTP 下载，鉴权放请求头；拒绝外部服务器、反向代理目录外地址和重定向，剔除 URL 中的令牌参数。
- 播放引擎按需加载，限制分片大小及前向缓存。

## 已验证

- npm test：78 项通过。新增覆盖路径与令牌处理、续播位置、播放协商、204 空响应、分片请求失败及取消。
- npm run build：类型检查和生产构建通过。
- npm run test:heic：浏览器回归通过，包括 Jellyfin 播放入口、服务拒绝提示、重试、关闭以及 390px 手机布局。现有 NAS 视频播放等回归通过。
- 浏览器中 Jellyfin 使用模拟接口；不把这些结果作为实际 Jellyfin 转码播放成功的证据。

## 待验证

- 连接用户真实 Jellyfin 服务，播放 H.264、HEVC 等媒体，验证首帧、拖动和长时播放。
- 多音轨、内嵌/外挂字幕、字幕烧录权限及切换后的时间位置。
