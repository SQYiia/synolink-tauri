# P1：文件分享、压缩解压与任务控制（待 NAS 验收）

实现日期：2026-11-13。版本保持 0.1.19；保留 Jellyfin 播放改动和 P0 待安卓真机验收状态，不提前发布 0.1.20。

## 已实现

- Windows 文件右键、安卓长按/更多操作支持单项分享、创建压缩包和整包解压；批量栏支持多选压缩。
- 分享默认随机 12 位字母数字密码、本地日期起 7 天有效，可修改密码、取消密码或选择到期日。NAS 返回链接后可复制链接、密码或完整信息；复制不可用时提供可选中文本。
- 分享管理每页 50 条，显示密码保护、有效期、状态，支持刷新、复制与确认后撤销。创建结果不确定时禁用再次创建，并引导先查看管理列表。
- ZIP/7z 使用普通压缩级别，支持可选密码。检查目标不在源目录内部；提交前读取目标目录，发现同名压缩包时要求改名。默认文件名可由用户调整，不提供已有压缩包更新入口。
- 整包解压保留内部结构，默认建立同名子目录且不覆盖；覆盖需二次确认，错误密码显示明确提示。
- 复制、移动、压缩、解压支持查询和取消。任务可能没有百分比，使用不确定进度；NAS 返回完成且没有整体/逐项错误才显示完成。
- 提交、查询、取消使用捕获来源身份的客户端，切换账号/会话后丢弃旧结果。重新登录来源账号后可重新查询原任务，不重复提交。
- 传输中心按服务器和账号过滤；取消失败保留等待查询，移除记录明确不等于停止 NAS 任务。已完成文件操作不回滚。
- 完成、部分失败、取消后使相关目录失效，可见页面自动刷新，KeepAlive 返回时补刷。上传保持原有流程，并接入目录刷新。
- 任务持久化使用字段白名单；密码、认证信息、请求体和原始异常不保存。旧运行任务恢复为等待查询。
- 修复安卓操作面板 callback 被重复执行的问题。

## 接口依据

参照 [Synology File Station 官方 API 文档](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Package/FileStation/All/enu/Synology_File_Station_API_Guide.pdf)。使用 Sharing/CopyMove/Compress v3 与 Extract v2，先通过 API Info 检查支持范围。Compress 普通压缩级别为 `moderate`；仓库旧文档中的 v2/normal 不用于新实现。路径、任务 ID、密码等字符串和路径数组按接口 JSON 参数编码。

压缩同名检查是提交前检查，官方 Compress 没有独占创建参数。如果另一个客户端在检查后同时创建完全同名文件，不能保证原子排他；建议使用独立文件名。未增加额外的临时归档或发布步骤。
