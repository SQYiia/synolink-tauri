# Windows 桌面设计改版（首批）

2026-11-14。使用已安装的 Anthropic `frontend-design` skill 指导改版，来源：https://github.com/anthropics/skills/tree/main/skills/frontend-design 。该 skill 安装在用户 Codex skills 目录，不作为应用运行依赖。

## 设计方向

定位为长期使用的 NAS 桌面工作区。信息可读性与文件操作效率优先，不使用装饰性大标题或营销卡片。

- 颜色：工作区底色 #F5F7FA、内容面 #FFFFFF、正文 #212A3B、次要文字 #606A7B、边界 #DDE2E9、操作蓝 #1B63D0。实际 CSS 使用对应语义 HSL tokens，并提供深色映射。
- 字体：Windows Segoe UI Variable / Segoe UI，中文 Microsoft YaHei；页面标题 26px，正文/导航 13px，辅助文字 11–12px。
- 布局：224px 分组侧栏 + 58px 顶栏 + 32px 内容边距；窄桌面缩减侧栏与边距，操作区换行。列表左对齐，主要动作固定在标题右侧。
- 层级：工作区、媒体资料、NAS 管理三组；服务器与账号作为工作区上下文；上传为主操作，回收站/分享为次要入口。

## 本批实际变更

- 桌面导航新增显式概览、Drive、备份与容器入口，保留媒体、应用、性能、虚拟机、设置。服务器卡片使用实际保存名称和账号，不显示未经探测的在线状态。
- 顶栏展示当前位置和全局搜索；Ctrl/Cmd+K 打开搜索，传输中心保留独立入口。
- 文件页分为标题/主操作、目录导航/搜索、文件列表/状态栏。路径输入按需展开，长文件名截断后可查看提示。
- 统一桌面按钮、弹窗、表格、间距与明暗色变量；样式置于 desktop.css，仅在宽于 640px 时生效。
- 右键菜单等待定位后使用 preventScroll 聚焦，外部滚轮关闭菜单，避免弹窗焦点恢复产生的程序滚动误关菜单。
- 本批没有重写每个业务页面。应用中心、监控、媒体详情等仍需逐页设计，不将全局样式调整标为所有页面完成改版。

## 验证

- `npm run test:desktop`：实际 AppShell + Files 组件，模拟 NAS 数据；浅/深色、1440/1100/900/760 宽度无横向溢出，快捷键搜索、传输抽屉和路径输入通过。
- `npm run test:files` 与 `npm run test:recycle`：文件分享、压缩、批量改名、回收站等交互回归。
- `npm run build`：Vue 类型检查及前端生产构建。
- 截图位于 `.npm-cache/desktop-design/`，其中内容为测试数据，不是真实 NAS 文件。
- 未以真实 Windows WebView2、系统缩放或安卓设备执行视觉验收；浏览器测试不替代原生设备验证。不改变现有 0.1.20 待统一验收发布安排。
