# P2 文件批量重命名

在 P1 文件操作与自动相册备份之后，优先补齐高频文件整理操作。版本仍为 0.1.19，不发布 0.1.20；P0、自动相册备份的真机待验收状态不变。

## 功能范围

- Windows：多选工具栏、多个项目的右键菜单进入“批量重命名”。安卓：长按选择“多选”，勾选项目后使用工具栏“重命名”。
- 支持同一目录 1–500 个文件或子目录；不允许修改共享目录，不支持跨目录批次。
- 按选择列表顺序生成序号，支持起始值、补零位数、前后缀和字面文字替换。文件保留最后一个扩展名，目录名称按完整名称处理；不提供正则表达式及扩展名修改。
- 提交前显示原名、新名和冲突。拒绝非法字符、Windows 保留名称、超过 255 UTF-8 字节的名称，以及本批重复或已存在名称。对大小写及 Unicode 规范化近似名称采取保守拒绝策略；不支持交换名称或只改大小写。
- 提交时使用绑定来源账号的客户端，发现 Rename v2 后重新读取完整目录，检查源项目存在及同名冲突。逐项调用 JSON 数组参数，并核实 NAS 返回的目标路径和逐项错误。
- 任一失败或响应不完整即停止后续请求；请求中断显示“待核实”，不自动重试、不回滚。停止按钮不能撤销已经发给 NAS 的当前请求。
- 切换账号、离开页面或关闭组件停止后续调度；已经发出的请求仍可能完成。完成、失败或结果不明均标记来源目录需刷新，KeepAlive 页面恢复时补刷。
- 当前批次结果仅存在本次弹窗内，不落盘、不在传输中心恢复，不支持后台批量重命名。关闭后需要以 NAS 目录实际内容为准。

## 验证

- Node 自动回归 91 项通过，其中新增 6 项覆盖命名规则、冲突、扩展名、保留名称、超长名称、非法序号、顺序写入、停止、账号变化、部分失败、未知响应和接口参数编码/能力缺失。
- `npm run test:files` 通过：桌面多选预览、非法名称禁用提交、安卓长按多选、长文件名与窄屏布局、成功后自动刷新、提交前目录新增冲突、停止后只完成当前请求、账号切换丢弃后续调度，以及已有分享/压缩/解压回归。
- Vue 类型检查与前端生产构建通过；安卓 ARM64 编译用于兼容性检查，不作为真机验收或正式发布。
- 尚未在真实 NAS 上执行批量重命名，NAS 接口兼容性、权限拒绝、并发外部改名和实际文件内容保持不变待验收。预检与提交之间仍可能发生外部目录变更，遇到 NAS 冲突/错误会停止并要求刷新核实。

接口参数依据仓库 `doc/Synology_FileStation_API.md` 第 18 节（Rename v2）；此次未对真实 NAS 执行写操作。
